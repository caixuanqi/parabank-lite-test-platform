## 二、业务规则

### 2.1 登录模块规则

1. 用户名必填，长度 6 ~ 20 位
2. 用户名只允许字母、数字、下划线
3. 密码必填，长度 6 ~ 20 位
4. 密码只允许字母、数字和字符 @ # $ . _
5. 用户名必须已在系统中注册
6. 密码必须与注册时一致
7. 用户名或密码任一为空时，不允许提交

### 2.2 注册模块规则

1. 用户名必填，长度 6 ~ 20 位
2. 用户名只允许字母、数字、下划线
3. 用户名必须全局唯一，不能与已有账号重复
4. 密码必填，长度 6 ~ 20 位
5. 密码必须同时包含字母和数字，且只允许字母、数字和字符 @ # $ . _
6. 确认密码必须与密码保持一致

### 2.3 转账模块规则

1. 转账金额必填
2. 金额范围 0.01 ~ 50000.00 元
3. 金额最多保留 2 位小数
4. 金额只能包含数字和一个小数点
5. 源账户余额必须 ≥ 转账金额
6. 源账户和目标账户不能相同
7. 目标账户必须存在

### 落地口径（相对文档的偏差）

| 模块 | 规则 | 落地口径 |
|------|------|----------|
| 注册 | 用户名必须全局唯一，不能与已有账号重复 | REG_010 文档用 admin 触发，但 admin 只有 5 位、过不了 6~20 长度校验，落地改用预置账号 admin_01（8 位，已注册） |
| 注册 | 密码必填，长度 6 ~ 20 位 | REG_015 文档写"21位合法字符"，落地用 21 位合规密码 Pass12345678901234567 |
| 转账 | 金额只能包含数字和一个小数点 | TRAN_07（-50）要求提示"金额必须大于 0"，故校验顺序为：字符集 → 小数点个数 → 格式 → 小数位 → 数值范围；负号放行到数值校验 |
| 转账 | 源账户余额必须 ≥ 转账金额 | 预置账户 10003 余额 100.00，供 TRAN_14（余额不足）使用 |

## 九、一致性校验

```bash
python check_consistency.py --online   # 用例表 / 被测系统 / 平台库 / pytest / 执行结果 / 文档
```

被测系统、平台库、pytest 套件、本文件均由 `testcase_spec.py` 派生，任何一处改动都会被校验脚本发现。其中"平台执行结果"一项会比对三个套件最近一次执行的实际失败集合与缺陷清单（4 条），多失败或少失败都会报错。
